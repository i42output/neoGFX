# neoGFX images

`settings.svg` is the Fluent UI System Icons `settings` icon (regular style, 20 px design) from the `@fluentui/svg-icons`
package, version 1.1.345, licensed under the MIT License (see `../icons/LICENSE`). Modified for neoGFX: its width
and height were changed from 20 to 256 and it was given a pastel fill colour (indigo 200 from the Material Design colour
palette).
