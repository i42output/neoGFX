# neoGFX icons

Except `neoGFX.png` (the neoGFX logo), `reverse.svg` and `reversepartial.svg`, these are Fluent UI System Icons (regular style,
20 px design; `bookmark_small.svg` uses the 16 px design) from the `@fluentui/svg-icons` package, version 1.1.345, licensed under
the MIT License (see `LICENSE` in this directory).

Modified for neoGFX: each icon's width and height were changed to the size of the PNG icon it replaces
and each shape was given a fill colour: a pastel (200 shade) from the Material Design colour palette, or white for
the icons neoGFX tints with the theme's text colour (bookmark, bookmark_small, delete, eye-outline, reverse and
reversepartial).

The file icons (new, open, openfolder, save and print) share one colour (blue, #6EC0FF), as do the clipboard icons
(cut, copy and paste: white).
