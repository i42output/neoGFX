# Test app icons

Material Design icons (filled style) from the `@material-design-icons/svg` package, version 0.14.15,
licensed under the Apache License 2.0 (see `LICENSE` in this directory).

Modified for the test app: each icon's width and height were changed from 24 to 32 (the toolbar's
default button image size, so they rasterise at full resolution) and each path was given a fill colour
from the Material Design colour palette.
